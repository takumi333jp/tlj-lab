TLJ Chord Player

Mizouのリンクから開くとコード進行が自動入力されます。スマホでは「▶ 音を準備して再生」をタップすると、その操作の中でWAV音源を作成して再生します。

「▶ 音を準備して再生」を押してください。
iPhone / Android向け：最初のタップそのものを音声再生のユーザー操作として使います。うまく鳴らない場合は、生成後に表示される「別画面で音源を開く」を使用してください。

サンプル
Cmaj7–Am7–Dm7–G7 Dm7–G7–Cmaj7–Cmaj7 Cmaj7–A7–Dm7–G7 Cmaj9–A7b9–Dm9–G13
対応例：C, Cmaj7, Cmaj9, C13, C7b9, C7#9, C7#11, Cm9, Cm7b5, Cø7, Cdim, Cdim7, Csus4, Cadd9。
Mizou用URL例：?c=Cmaj7,A7,Dm7,G7&bpm=90&beats=4
テンション対応：9 / b9 / #9 / 11 / #11 / 13 / b13 / add9 / 6/9 / b5 / #5 など。
高いテンションは実用的な音域へオクターブ移動し、トップノートが極端に高くならないJazz Voicingで再生します。
